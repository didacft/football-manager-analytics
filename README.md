# Football Manager Analytics

Football scouting and analytics project using player performance and market-value data.

## Tech Stack

- Python
- DuckDB
- Git / GitHub

## Data Sources & Credits

### Player, club, competition, appearance, transfer and market-value data

The main analytical dataset comes from:

- **[transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets)** by David Cariboo

That project provides clean, structured football data built from publicly available **Transfermarkt** information. This repository uses the published dataset rather than scraping Transfermarkt directly.

Market values in the project should be interpreted as **Transfermarkt market-value estimates**, not as actual transfer fees or objectively observed market prices.
